# DunD

A lightweight Dungeons & Dragons table companion that runs entirely in the browser.
No install, no build step, no account — just open `index.html`.

Built to sit next to a table that rolls real dice and uses paper character sheets.
The default **Player view** keeps monster HP and AC hidden unless you have learned them,
and every roll can be typed in from the physical dice instead of generated by the app.

## Run it

- **Quickest:** double-click `index.html`.
- **Optional local server** (handy on a tablet or for multiple browser windows):

  ```powershell
  python -m http.server 8000
  ```

  Then open <http://localhost:8000>.

Everything is stored in `localStorage` on the device, so it keeps working offline
at the table.

## What's inside

| Tab | What it does |
| --- | --- |
| **Character** | A player dashboard that can be as light or as full as you want: a real class and subclass (hit die, saving throws, spell slots, class resources and level-based class features are applied automatically), HP and temp HP, death saves, conditions, ability scores and saving throws, all 18 skills with one-click rolls, attacks with attack/damage rolls, spell slots, spell save DC and attack bonus, prepared spells, limited-use resources, hit dice, inspiration, speed, AC, passive perception, currency, features, inventory, notes and a portrait. Short/long rest buttons restore the right resources. |
| **Combat** | Initiative tracker with rounds and turns, roll initiative for the party, damage/heal, conditions, PC death saves, battlefield status for monsters, encounter log, long rest. |
| **Dice** | Dice expression parser (`2d6+3`, `4d6kh3`, `2d20kl1`, mixed dice), advantage/disadvantage, quick d4–d100 buttons — **or type in the result of real dice** and let DunD add your modifier. |
| **Party** | Character roster with portraits, AC, level, passive perception, HP controls and notes. Shared with Combat, so HP stays in sync. |
| **Bestiary** | Searchable list of ~95 SRD monsters (CR, AC, HP, XP), one-click add, plus an **encounter XP builder** with Easy/Medium/Hard/Deadly thresholds. |
| **Notes** | Campaign name plus auto-saving session notes; copy or download as Markdown. |
| **Reference** | Conditions, combat actions, cover, death saves, concentration and DC tables for quick lookups. |

## Using it as a player

- **Player view** (top-right toggle, on by default) hides monster HP and AC. Mark a
  monster's stats as known from its **Edit** panel once the DM reveals them.
- Monster rows have a **Status** dropdown (Fine / Hurt / Bloodied / Down) for what the
  DM calls out, so you can follow the fight without knowing exact numbers.
- **Roll initiative** only rolls for your party in player view; fill in monster
  initiative as the DM calls it (click a monster's initiative badge to jump the turn there).
- You only need to enter the HP, AC and resources you actually track — everything else
  can stay on your paper sheet.
- The character sheet includes optional ability scores, saves, all 18 skills, attacks,
  spellcasting stats, hit dice, inspiration, currency and gear. Anything you leave at
  10 or blank simply works as a default; rolls are one click from the sheet.
- The class picker is real: choose one of the 13 classes (or a homebrew name). Picking a
  class or changing level applies that class's hit die, saving throws, spell slots,
  pact magic and class resources, and shows its class features for your level. Subclass
  suggestions come with each class.
- Switch the header toggle to **DM view** to see full monster stats and roll initiative
  for the whole table.

Add combatants manually, or pull them from the bestiary. Click the big initiative
number to jump the turn to that combatant (or click **—** to type in the initiative
the DM calls out), and **Next turn** advances the round automatically.

## Keyboard shortcuts

- `N` — next turn (starts combat if needed)
- `R` — jump to the dice expression field
- `Alt` + `1…7` — switch tabs
- Arrow keys — move between tabs when a tab is focused

## Saving

- Everything auto-saves as you go.
- **Export** downloads a JSON snapshot (usable as a backup or to hand to the DM);
  **Import** restores one.
- **Reset** clears the local save.
- **Long rest** in the header restores all party hit points, spell slots and resources.
  The Character tab also has per-character **Short rest** / **Long rest** buttons.
